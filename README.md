# Blissbreath Collective

The Blissbreath sanctuary — breathwork, the 365-day Path, plant-based recipes, a 7-day reset, journal, and a classical Ayurvedic sitting.

Live: [app.blissbreathcollective.com](https://app.blissbreathcollective.com)

Hash rooms from the earlier PWA (`#reset`, `#nourish`, `#path`, `#breathe`, `#journal`, `#dosha`) still land on the matching rooms.

## Local

```bash
npm install
npm run dev
```

Auth and the shared database stay off; the journal, Path progress, and reset live in the browser.
